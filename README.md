# GST Return Upload & Management Portal

Frontend-only React/Vite application using JavaScript/JSX, Tailwind CSS, React Router, Lucide React and Recharts.

## Run

```bash
npm install
npm run dev
```

Demo login:
- Email: `admin@gstportal.com`
- Password: `admin123`

## Important

This application uses mock data and browser localStorage only. It does not connect to GSTN, submit GST returns, validate GSTINs against government systems, or perform real uploads.

## Stack

- React + JSX
- Vite
- Tailwind CSS via `@tailwindcss/vite`
- React Router
- Lucide React
- Recharts
- localStorage

No TypeScript files are included.
